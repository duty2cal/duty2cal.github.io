Duty plan to calendar

Turn one supported duty plan into a calendar file. The plan stays in this tab.

Before you choose a plan

  • This tool converts a crew duty plan into a calendar file.
  • Convert here, in a current browser, with no installation.
  • Downloads for various operating systems are available on request; the release page carries the published builds.
  • Processing happens in your browser: no file is uploaded, nothing is stored, and no request is sent after the page loads.
  • The project is not affiliated with any duty-plan provider or airline.
  • The software is provided as is, without warranty of any kind.
